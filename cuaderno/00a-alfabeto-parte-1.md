# Lección 00a — El alfabeto, parte 1: amigas y falsas amigas

> Nivel: cero absoluto. Puentes: español e inglés.
> Objetivo: leer 12 letras (casi la mitad del alfabeto) y ya poder leer palabras reales.

## Grupo 1 — Las amigas (se escriben y suenan como en español)

| Letra | Sonido | Ejemplo |
|---|---|---|
| А а | a | **мама** = mamá |
| К к | k | **кот** = gato |
| М м | m | |
| О о | o (con acento) | |
| Т т | t | **там** = allí |

## Grupo 2 — Las falsas amigas (parecen latinas, suenan distinto)

| Letra | Suena | Truco para recordarla |
|---|---|---|
| В в | **v** (como en inglés *very*, con labio y dientes) | «B que hace V» |
| Е е | **ye** (*yes*) | |
| Ё ё | **yo** (*yogurt*); siempre lleva acento | Е con dos puntos |
| Н н | **n** | «H que hace N» |
| Р р | **r** vibrante (*pero*, *perro*) | «P que hace R» |
| С с | **s** | «C de *cent*» |
| У у | **u** (*food*) | «Y que hace U» |
| Х х | **j española** (*jamón*, escocés *loch*) | «X que hace J» |

## Regla de oro n.º 1: la О sin acento suena «a»

El ruso no escribe el acento (en los libros para estudiantes sí). Cuando la **о** no lleva el acento, se pronuncia **a**:

- **Москва́** → *Mask-VÁ*
- **молоко́**, «leche» → *ma-la-KÓ* (esta palabra tiene una letra del próximo grupo: Л = l)
